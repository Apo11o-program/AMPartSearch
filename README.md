# A.M. Part Search (Spaceflight Simulator mod)


Search **every loaded part** while in build mode - by display name, part id, or
description. No more digging through category tabs to find that one nose cone.

## Usage
1. Enter **Build mode** - a "Part Search" window appears (minimizable, remembers position).
2. Type: `nose`, `heat shield`, `frontier`... results update as you type.
3. Click **details** under a result to print its full description to the in-game message drawer.

Requires **UITools 1.1.5+** in your MODS folder.

## Install
Drop `AMPartSearch.dll` into  
`Mods/PartSearch/`

## Building
See `AMPartSearch.csproj` - repoint the HintPaths at your install, then build (VS/Rider/dotnet).
